# The words Kontexto refuses with "Dieses Wort zählt nicht, es ist zu allgemein".
#
# A port of the original game's list, not a list of its own. On 2026-09-24 the
# public Contexto API (api.contexto.me/machado/en/game/<n>/<word>) was asked
# about 408 English candidates, every entry of the NLTK and spaCy stopword lists
# plus the borderline cases. It refused 178 of them as "too common" and ranked
# everything else, rare words included: "leggings" came back at 25.638.
#
# What the original refuses, by class, and what this file carries for each:
#   articles, all pronouns (personal, possessive, reflexive, demonstrative,
#   interrogative, relative, indefinite), the basic prepositions, conjunctions,
#   the auxiliaries be/have/do and the modals can/could/will/would/should, the
#   determiners and quantifiers all/any/some/each/every-one/few/both/several/
#   enough/no/none/such/same/other, and a short run of adverbs: here, there,
#   then, now, once, again, very, too, so, just, only, also, else, ever, quite,
#   sometimes, today, not, how, when, where, why.
#
# What the original ranks, and this file therefore leaves out on purpose:
#   many, much, more, most, less, little, never, always, often, still, already,
#   yet, soon, almost, maybe, rather, really, even, well, please, yes, oh, okay,
#   must, may, might, shall, want, need, every number word, and the spatial
#   prepositions behind, beside, beyond, inside, outside, near, along, across,
#   among, around, toward, within, via, despite, except, instead, since, till,
#   plus according and thanks. In German that keeps viel, mehr, meist, wenig,
#   nie, immer, oft, schon, bereits, bald, fast, vielleicht, wirklich, sogar,
#   bitte, ja, nein, müssen, dürfen, mögen, wollen, hinter, neben, innerhalb,
#   außerhalb, entlang, gegenüber, trotz, außer, statt, seit, laut and dank on
#   the scale. "nein" follows "yes" rather than "no": the English "no" is also
#   the determiner, which is "kein" here.
#
# "meinen" is missing from the possessives and "einigen" from the quantifiers on
# purpose: they are also the verbs for "to mean" and "to agree", which players
# type as content words.
#
# The list names base forms and the inflected forms of each. A form missing
# here is still refused when the build reads its lemma as one of these words,
# so the inflections are listed for the record and for the runtime check, which
# reads this file directly and does not depend on the build.
#
# Held by backend/test_stopwords.py: every entry of prepare.GERMAN_STOPWORDS is
# in here, no solution is, and nothing the original ranks has crept in.
