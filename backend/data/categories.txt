# The category catalogue: what a solution may be filed under.
#
# Why categories exist: since 2026-10-01 a player can pick the fields a round is
# drawn from (only animals, only food and drink) or play every field and see the
# round's field above the board. The daily and the standard modes never show
# one. Where they appear and why: CLAUDE.md, section "Categories".
#
# Format, one category per line, in the order the picker shows them:
#
#   id = Display name: seed words
#
# * id is an ASCII slug and never changes once shipped, because rooms store it
#   and an old client sends it. The display name is the German UI copy and may
#   change freely.
# * The seed words are not read at runtime. scripts/propose-categories.py reads
#   them to propose a category for every solution (the solution's own rank
#   array says how close each seed sits), and scripts/measure-categories.py
#   reads them to measure how much showing the category helps. They are
#   everyday words a player would type once they know the field.
#
# One level, no subcategories. A category must keep at least
# categories.MIN_PLAYABLE solutions (40) after the struck games are removed, so
# that a player who picks only that one does not meet the same word again for
# several evenings; test_categories.py holds it.
#
# The abstract words have fields of their own (feelings and thoughts, concepts
# and ideas), because the player ruled that every solution gets a category.
